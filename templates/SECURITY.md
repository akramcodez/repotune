# Security Policy

## Supported Versions

Please check the repository for the versions currently being supported with security updates.

## Reporting a Vulnerability

If you discover a potential security issue in this project, please report it privately. Do not open a public issue.

You can report vulnerabilities directly via email to the project maintainers at {{email}}.

We will try to respond to all reports within a reasonable timeframe, providing an initial assessment of the vulnerability and an estimated timeline for a fix.
